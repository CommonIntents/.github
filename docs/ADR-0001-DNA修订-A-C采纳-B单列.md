## 1. 背景

九轮审计产出 K-059…K-107。其中三条**反复发生**的规律（证据密度分别 7 / 6 / 4）已在
`CI-144_DNA修订提案.md` 中成文，但**当时未改 `DNA.md` 一字** —— 因为提案自己写明"需人类批准"。

本 ADR 记录人类批准后的**落点与做法**，使"改 DNA"这个宪法级动作**先有决策、后有变更**（原则 3）。

### 1.1 为什么这次可以改，而之前不可以

| 维度 | 说明 |
|---|---|
| **不是加新公理，是补缺的工程映射** | A 落原则 1 与原则 4；C 落原则 1 —— **公理数不变的假设对 A/C 成立** |
| **B 是唯一改公理数的一项** | 它跨闸门/守卫/注册表/合法集四类，**不属于任何单一既有原则** ⇒ 单列 |
| **D/E 证据密度不足** | 1 案 3 站点 / 2 例 ⇒ 立原则会让宪法记下"当时的想法"而非"反复发生的规律" |

## 2. 决策

| # | 决策 | 落点 |
|---|---|---|
| **1** | **采纳 A** —— 未知必须显式表示；危险的是「缺失缺省」 | 补入**原则 4** 的工程映射 |
| **2** | **采纳 C** —— 判据必须指向"实际被消费的那个对象"，不得指向其代理 | 补入**原则 1** 的工程映射 |
| **3** | **采纳 B，单列第七条** —— 机制的覆盖范围必须与其声明的范围一致 | **新增原则 7**（公理数 6 → 7） |
| **4** | **D / E 先观察，暂不提** | 不写入 DNA；继续留在提案 §2 观察 |
| **5** | **落协议家族层一次** —— 只改 `commonintents/.github/DNA.md` | 各仓**引用不复制**（唯一事实来源） |

**⇒ 第 3 项是本 ADR 唯一的宪法级数字变更**：`6 条公理` → `7 条公理`。
⇒ 因此**凡断言"6 条"的处所必须同步**，否则即产生**本 ADR 自身要防的那类漂移**（通则 B）。

### 2.1 同批裁定（S-1 的规范层问题，契约 §11 Q-FIX-2）

同一次裁决中，人类另就 **S-1**（Tuck 单比特无条件放行）给出规范层裁定：

| 项 | 裁定 |
|---|---|
| **选择** | **A —— 改"谁来断言"**：保留规范的"不可协商"语义（**不改** `pfp-xcf14.md:154`），但要求 `Override-Flag` **来自可鉴权来源** |
| **实施路径** | 把安全证明的**覆盖范围扩展到 PFP 的判定位**，走 SAP 规范**已预留**的演进通道（`sap-xcf14.md:29`「未来可扩展新的安全证明机制」） |
| **前置** | **S-2 先行**（`None` 不得等于 `Pass`），且**带观察期（shadow 只记不拦）** —— 没有 SAP 就没有可鉴权的来源 |

**为什么不选 B/C（依据见 `CI-144_合拢坑记录.md` K-107）**：原问题是一个**假二分**。
`pfp:152/154` 把无条件放行定为**规范要求**并自称"不可协商"，故"取消放行"实际是**改规范**而非改代码；
而该 bit 与降级位同处**一个未签名字节**（K-012）⇒ 帧构造方同时握有"取消紧急"与"自述紧急"。
⇒ **真问题是断言权，不是放行语义。** 选 A 恰好落在规范已预留的扩展点上。

## 4. 被放弃的替代方案（**为什么没选**）

| 替代 | 放弃理由 |
|---|---|
| **B 并入原则 3**（不动公理数） | 原则 3 是"决策先于变更（ADR 强制）"，与"覆盖范围＝声明范围"**不同族**。并入会把一条跨四类的规律塞进一条讲流程的原则里，**降低两者的可判定性** |
| **A/C/B 全部各仓各自改** | 违反唯一事实来源；且**已经发生过一次**同根因分叉（K-012 / K-105 三处同族） |
| **D/E 一并立为原则** | 密度 1 案 3 站点 / 2 例。**立原则的判据是反复发生，不是听起来对** |
| **先改 DNA，稍后补 ADR** | 违反原则 3 本身；且 DNA 自称"最高裁判"，**用违宪的方式修宪**不可接受 |

## 6. 后果

- **正面**：三条反复发生的规律从"文档里的想法"变为**宪法条文**；后续审计可引 DNA 而非重新论证。
- **代价（不粉饰）**：**公理数从 6 变 7**，旧身份的信用按 DNA 自己的声明**不转移**。
- **未决**：D/E 仍在观察；**B 的新增是否会在各仓派生"覆盖范围断言"的落地义务**，
  属后续工作（与 I5 同族），**本 ADR 不代为决定**。
