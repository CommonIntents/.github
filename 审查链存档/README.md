# 审查链存档

> 建立：2026-09-18 ｜ 状态：**索引层（C 类，不进决策链）**
> 用途：让 CI-144「之间」的**外部审查链可被追溯**，并**明确记下这条链缺了什么**。

---

## 0. 这是什么，不是什么

**是**：一条**外部审查意见 → 我方逐条答复**的链的**索引与缺口登记**。
**不是**：不是规范、不是决策、不是约束。与四仓源码或规范冲突时，**以源码与规范为准**。

**归属声明**：本链的审查意见由**沙盒侧生成**（非 `.github` 仓的常规产物），
**未经仓库维护者逐条签署**。它的价值在于记录"某条结论是如何被推翻或确认的"，
而不在其自身权威。**按归类规则全部属 C 类。**

**设计约束（来自本链自己的原则）**：`CI-144_之间的形式_计划与审查.md` §2 写明
「家族层只放**索引 + 坑记录 + 冻结账**，**不放事实本身**」。
⇒ **本目录不复制链上文档**。复制会产生两份副本，正是 K-002/K-003 那一类分叉缺陷。
⇒ 本目录只登记**指针 + 缺口**。

## 1. 账目现状（2026-09-18 实测，非转录）

| 账 | 位置 | 实测 |
|---|---|---|
| **A** | `.github` 仓 git | ✅ **链上 7 份文档全部 TRACKED**，见 `索引.md` |
| **B** | 沙盒 `/data/workspace/` | ⚠️ **本会话不可达**：`ls /data/workspace/` → `No such file or directory` |

**⇒ 关键实测结论（修正了我先前的判断）**：
链上**答复稿**从未缺失——**7 份全在 git 里**。
真正缺的是**审查意见原稿**：`git log --all --diff-filter=A --name-only | grep 审查` **零命中**，
即**原稿从未入库**。这些原稿只可能存在于账 B。

**⇒ 因此本目录登记的是"半个链"**：`答复` 一侧完整，`审查意见` 一侧缺失。
**`答复` 不是原稿的替代品**——它引用并回应原稿的论点，是**有损记录**，不是原文。

## 3. 为什么值得留（别处没有的资产）

**代码可以重写，方法不能。**

| 资产 | 首次出现 |
|---|---|
| **裁决实验**：判一个检查测的是 X 还是 Y，就构造「X 变 Y 不变」与「Y 变 X 不变」，看它红不红 | 答复四 |
| **审计断言化**：任何"去查"项先问"能不能写成断言"；不能才标人工审计并写明原因 | 答复四/六 |
| **阳性对照**：阴性结论（零命中）必须带正对照，否则不下结论 | 答复三（首次使用） |
| **同族错误列表**：默认值把「缺失」伪装成「合法取值」——多次复发，且**由机制本身掩护** | 答复四 §0.2 |
| **原则单独使用会造洞**：一条原则用到极致会产生它本要防的洞（"反讽"） | 答复三 |
| **校验器不得严于消费者** / 自证必须可验证 | 答复三·六 |

## 4. 本目录适用规则

1. **全部标 C 类**，不驱动动作。
2. **不得因本目录而停止 git 内的记账**：坑记录 / 决策索引 / 更正史仍是唯一入口。
3. **不复制链上文档**（见 §0 设计约束）；只登记指针与缺口。
4. **不得把审查意见当规范引用**；若某条被采纳，落点必须在四仓的 ADR / 坑记录 / CI 规格里。
5. **不得凭记忆重写缺失原稿**。缺就记缺。
