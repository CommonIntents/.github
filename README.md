
| 门禁 | 管什么 |
|---|---|
| **CI-4** | 测试向量：声明与实测双向对齐（BIND-19 仓） |
| **CI-6** | NCLOC 预算 · ratchet（只降不升）· 六类额度账本 · churn 判据 |
| **CI-7** | 每条 guard 的变异必须**指名**变红，且编译必须成功 |
| **离线变异器** | 一行代码被改坏而全套测试仍绿 ⇒ 那是没人守的地方 |

**离线变异器为什么自建**：`cargo-mutants` 在本环境**结构性不可用**（crates.io 403、无镜像、无 vendor、无缓存）。
**它不是替代品**，是条件满足前的过渡；接口按同一份输出设计。
**⇒ 它自己的对照**：`--selftest` 注入一个**必须被抓死**的变异并要求 caught。
